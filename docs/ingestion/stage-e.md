# Этап E: shadow-маршрут подтверждённой модели

Пакет `calendar_pedagoga.ingestion_shadow`. Production UI и `run_calendar_pipeline`
его не импортируют. `SHADOW_ENABLED` остаётся `False`.

## Путь

Один и тот же вызов для любого документа:

`ingest(path)` один раз читает исходный файл и строит структурную модель.
Дальше `run_shadow(session)` работает только с подтверждённой Session:

canonical extraction → structural interpretation → confirmation → Stage-D adapter
→ расписание и подтверждённые связи → существующий RESULT/CONTROL
→ календарные строки → DOCX.

Повторного разбора DOC/DOCX нет. Имена файлов, дисциплин, тем и программ
не выбирают ветку.

Источник плана берётся из подтверждённого Assessment: внешний УТП, иначе
встроенный, иначе ручной. Неподтверждённое, неоднозначное и конфликтное
состояние завершается `ShadowBlocked` до генерации. `docx` при блокировке
всегда `None`.

Часы теории, учебно-тренировочных занятий и практики не объединяются.
Недели берутся из явного `ExplicitWorkload` либо из единственной фразы
«N учебных недель» в каноническом тексте выбранного года; недельная нагрузка
должна точно давать подтверждённый итог. Дробные часы не отдаются в
allocator, который считает только целые часы.

Если существующий downstream возвращает пустой RESULT/CONTROL, generic-only,
неподтверждённый source или полный повтор schedule + type + RESULT + CONTROL,
маршрут останавливается с кодом `DOWNSTREAM_DEFECT` и не публикует DOCX.
Readiness-gates не изменяются.

Каждый слот получает источник только из подтверждённой модели того же года
и той же темы: канонический идентификатор, SourceSpan и порядок фрагментов
сохраняются. Фрагмент занимает не больше одного слота. Слот без фрагмента
использует заголовок строки УТП. Неоднозначная привязка блокирует слот
до CE2.

Повтор schedule + type + RESULT + CONTROL снимается существующим
распределителем `allocate_repeated_title_slots`, без второй реализации:

- разные канонические тексты, которые CE2 сводит в один кадр, останавливают
  маршрут кодом `SEMANTIC_COLLAPSE`; номер этапа им не подставляется;
- одинаковый текст, title-only и источник без различающих atoms на нескольких
  слотах одной темы и одного канала передаются в этот распределитель:
  однородный каталог делится непрерывно, иначе в SentenceFrame попадают
  `phase_index` / `phase_count`. RESULT и CONTROL собираются из этого кадра.
  Одиночный title-only слот сохраняет заголовок и в фазовую группу не входит.
