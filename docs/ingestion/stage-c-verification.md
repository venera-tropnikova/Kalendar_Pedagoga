# Этап C — отчёт проверки

Статус: **PASS / VERIFIED**, включая визуальную проверку всех восьми состояний
в браузере при 1366×768 и 390×844. До её завершения статус был
**FUNCTIONALLY VERIFIED**. База: `6767572` (этап B).

## Изменено

Добавлены изолированные модели C, чистые переходы восьми состояний, JSON-журнал
подтверждений, инвалидирование по исходнику/структуре и один renderer.
Подтверждение не меняет исходные A/B; неопределённые решения и противоречия сохраняются.
Различия планов показываются по исходному порядку строк, без matching.

Production, A/B и существующий `kp_parser_hardening` не изменены. Новых runtime
зависимостей нет. Shadow по умолчанию OFF; downstream не подключён.

## Проверено

Команда из ingestion worktree, `PYTHONPATH=src;.`:

```text
D:\Kalendar_Pedagoga\.venv\Scripts\python.exe -m pytest tests/lossless_document tests/structural_interpretation tests/ingestion_confirmation -q --tb=short
240 passed in 139.83s
```

- A+B: 148 проверок, включая прежние привязанные к источнику контракты и DOC-конверсию.
- C: 92 проверки — 75 переходов/property cases, 12 UI-тестов, 5 параметров реального corpus.
- Реальные файлы — единый manifest, одна функция проверки, одинаковый обход ветвей
  года/плана, одинаковые инварианты и тот же UI, что для синтетических мутаций.
- VALID: ровно одно подтверждение; HOURS_CONFLICT: кнопка недоступна и API отвергает
  подтверждение. Неизвестное значение не превращается в ноль.
- Проверены все восемь экранов, сохранение/восстановление ответов, смена исходника,
  смена структуры при прежнем исходнике, запрет подтверждения через поддельный журнал.
- Проверены точные дроби, перестановки колонок, шапки из 1/2/3 строк, объединения,
  раздельный/общий номер и название, количество кандидатов, годы и границы.
- После выбора колонок пересчитывается арифметика и проверяется применимость старых
  связей; границы не захватывают другой год или текст за подтверждённым концом.
- Проверены evidence и SourceSpan событий; архив сохраняет их при JSON round-trip.
- AST-проверка импортов: отсутствуют зависимости от legacy parsing, matching,
  scheduling, pipeline, генерации и production ConfirmedStudyPlan.
- Production-модули не импортируют C; названия corpus отсутствуют в runtime-коде C.
- `compileall` прошёл. SHA-256 всех 11 Python-файлов сверены с версиями,
  зафиксированными до финального тестового прогона.

## Визуальная проверка

Проверка выполнена в локальном shadow на `http://127.0.0.1:18501`, отдельно
разрешённом пользователем. Google Chrome / Playwright, два viewport,
16 основных скриншотов; дополнительно просмотрены раскрытые панели и низ длинных
экранов. Браузерные обращения ограничены этим адресом.

| Состояние | Desktop 1366×768 | Mobile 390×844 | Замечание |

| YEAR_AMBIGUOUS | PASS | PASS | Выбор года виден сразу; подтверждение открывает итоговый экран. |
| PLAN_AMBIGUOUS | PASS | PASS | Выбор перед сравнением; совпадающие таблицы не выбираются автоматически. |
| COLUMN_AMBIGUOUS | PASS | PASS | Неясная колонка показана первой; распознанные значения сохранены. |
| HOURS_CONFLICT | PASS | PASS | Продолжение недоступно; 5 против 4, разница −1; исправление видно сразу. |

Горизонтальных переполнений и необработанных browser pageerror: 0/16.
Все 16 сценариев действий прошли. VALID подтверждается одним нажатием;
HOURS_CONFLICT не создаёт событие подтверждения. Групповые связи остаются на
одной странице; подтверждённые пункты визуально отделены от ожидающих.

В renderer C исправлены расположение основного выбора, перенос длинного текста,
мобильное представление таблиц и выделение подтверждённых связей. Логика A/B/C
не изменена. После последней правки UI повторно прошли все 240 тестов.
