# Этап F: canonical ingestion в основном UI за флагом

Флаг `CANONICAL_INGESTION_ENABLED`. По умолчанию `false`.
Production-сценарий при выключенном флаге не вызывает новый экран и маршрут Stage E.

При `true` загруженный документ один раз проходит canonical extraction и
структурную интерпретацию. Источник плана выбирает подтверждение Stage C:
внешний план, иначе встроенный, иначе явно переданный ручной документ.
Экран один: «Мы нашли… Всё верно?» либо единственный вопрос текущего
состояния. После «Да, продолжить» календарь строится только маршрутом Stage E.
Возврата в прежнюю генерацию нет. Неоднозначность и конфликт показывают
сообщение и не создают DOCX.

Решения хранятся в сессии как JSON Stage C и сбрасываются, когда меняется
fingerprint источника. Имена файлов, дисциплин, организаций и тем ветку не выбирают.
